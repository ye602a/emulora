## 1. Make standalone renders and LUTs comparable · implemented

At the baseline, CLI `process` discarded the recipe on spectral initialization errors. `export-lut` always bypassed spectral calibration, disabled even local DIR and processed each grid node as a separate image. RS also accepted active UV/IR and adaptation surface fields without a spectral consumer. In the ordinary CPU fallback an active 135 border could disappear. FPW's versioned constructor and checked resident route have a different failure path.

The CLI now shares recipe/profile resolution between both commands. [Core baking](../crates/spektrafilm-core/src/lut_bake.rs) uses the photo constructor, keeps fixed trims and local chemistry, renders one grid and isolates GPU photo caches. The CLI atomically publishes a completed cube. A render or write error preserves the previous file. The [usage guide](USAGE.md#spectral-cube-export) defines the transport and what is omitted. Old and new exports have different looks. Existing CUBE files remain standalone artifacts. For the next engine change, compare against the pointwise photo on the **same backend** and distinguish exact grid nodes from interpolation on off-grid samples. [Batch measurements](ENGINE_STUDIES.md#spectral-cube-export)

OFX keeps local DIR in `lutSafeParams` and renders a whole grid. Python's reference tests permute neighbourhoods and exercise scene-wide dependencies. RS specifically gates frame-normalized highlight boost and both scan glare sources. A fixed manual print shift or preflash is part of the requested look in RS. Python experimental's neutral-bake convention also clears such per-image trims. [OFX source](https://github.com/chaert-s/spektrafilm-ofx/blob/86476af/src/SpektraFilmPlugin.cpp) · [Python bake tests](https://github.com/andreavolpato/spektrafilm/blob/28bf883/tests/test_lut_mode.py)

## 2. Give calibration changes one owner · next

- Move the distinction between calibration and dispatch inputs into RS. In [the constructor](../crates/spektrafilm-core/src/pipeline.rs) the midgray exposure factor uses film density gamma via [the enlarger](../crates/spektrafilm-core/src/enlarger.rs). The GUI's `preview_pipeline_cache_key` omits that gamma, and `with_params` retains the old factor. Gamma is exposed by the runtime API. The current GUI has no film-gamma widget, so this is an API refresh hazard rather than a reproduced slider defect. Compare a warmed gamma edit with a fresh construction. Also exercise print filters, preflash, development-time selection, spectral method and camera EV with exposure compensation on/off. Expose a checked refresh/rebuild decision before moving any additional knobs into FPW.
- The checked FPW adapter uses its own `PipelineKey` and disables print exposure compensation before patching camera EV at dispatch. The same stale-gamma trigger has not been established there. The host supplies immutable input identity and scheduling. RS already compares the actual prepared front tables, DIR, grain and border at the [negative-cache boundary](../crates/spektrafilm-gpu/src/negative_cache.rs). Add dependencies there only when a new upstream stage changes density.
- In [the standalone GUI](../crates/spektrafilm-gui/src/main.rs), the glare widgets edit `print_render.glare` even on a direct film scan. CPU scanning and resident preparation both select `film_render.glare` on that route. Bind controls to the selected stage, gate print-only controls, and check scan → print → scan with distinct saved values. The print-morph tooltip should describe evaluation of the fitted curve with morph off.
- A spectral constructor now rejects encoded input buffers, active camera UV/IR, adaptation surface and spectral Gaussian blur. The fitted Hanatos *window* runs today. Input chromaticity compression is baked into the Hanatos/Arctic tables. Mallett uses a matrix that has no such table. Decide whether to implement photographic transmission in spectral preparation or retire individual historical fields. Check the actual input **and** output transfer function before promising more transports. Keep wide-gamut architecture research separate. The generic neutral-table loader currently treats malformed and absent databases alike. Distinguish those cases before requiring new stock/paper calibration rows.

## 3. Deliver resources with their photographic process

**Portra NC/VC first if redistribution terms are established.** The four E-190 profiles include measured sheet curves, reconstructed dyes, extrapolated tails and fitted adaptation. LAB main carries a second file with 32 TH-KG3 film/paper rows, merged only into missing entries. Its digitizer/build inputs are described as untracked. The product notice distinguishes these files from the original CC BY-SA profile set. Record redistribution terms for this revision separately from the older B&W study.

In a temporary RS resource directory we ran all four films on Portra Endura using CPU f32 Hanatos and the same near-18% patch. Generic filter numbers produced a linear RGB max-minus-min of **0.1552–0.1762**. With the corresponding LAB row it was **0.00051–0.00054**. Settings used a neutral sRGB PNG code 118, manual exposure, local DIR, linear sRGB output and disabled optics/grain/glare. This validates the transfer of those four rows on one paper. Before packaging, verify all pairings, distinguish NC/VC from modern Portra across exposure and saturated colours, and preserve the existing resource identity. [Product data and provenance](https://github.com/JamesQiu2005/SpektraLab/blob/b51e672/engine/resources_product/NOTICE.md) · [Upstream pair tests](https://github.com/JamesQiu2005/SpektraLab/blob/b51e672/engine/tests/portra_nc_vc_checks.py)

**B&W as a complete second process.** The four converted negatives passed the earlier density/transmission study and remain outside the production resource directory. For black-and-white photography, integrate camera filter transmission with film sensitivity and expose a documented exposure-factor policy. LAB's Wratten tables have extrapolated ends and its No. 58 filter factor differs from the cited target by 0.67 stop. Keep the camera filter off the unexposed shoulder. Multigrade IV RC has three different paper emulsions, a grade pack and a print exposure per grade. RS must retain those emulsions through printing. Verify grey, red/blue reversal under the filters, monotonic wedge spans by grade and downstream-only invalidation when changing paper grade. [Conversion measurements](ENGINE_STUDIES.md#monochrome-profile-conversion) · [Filter data](https://github.com/JamesQiu2005/SpektraLab/blob/b51e672/engine/src/core/camera_filters.hpp) · [LAB black-and-white render checks](https://github.com/JamesQiu2005/SpektraLab/blob/b51e672/engine/tests/bw_checks.py)

## 4. Compare model changes before adopting a new look

| Candidate | Experiment that would change the decision |
| --- | --- |
| Optical diffusion | Reuse the [measured CPU/Vulkan PSF and photo crop](ENGINE_STUDIES.md#cpu-and-vulkan-diffusion). LAB fits a non-negative Gaussian pyramid with a near-field FIR and retains an exact lens reference. OFX selects 1×/2×/4×/8× per component at 12/24/48 px in auto. Compare impulse mass/radius, hard edges, point lights and real-photo residuals at equal pitch, then warm time, peak work memory, allocation and transfers. Prior bounce fusion saved dispatches with little gain on the measured photograph. [LAB lens](https://github.com/JamesQiu2005/SpektraLab/blob/b51e672/engine/src/pipeline/lens.cpp) · [OFX Vulkan](https://github.com/chaert-s/spektrafilm-ofx/blob/86476af/src/SpektraVulkanRenderer.cpp) |
| Negative-derived print hue | LAB mixes hue reconstructed from the negative with optical print lightness/chroma, weighted by curve slope, chroma and paper gamut. Compare violet fabric, skin, neutral ramps, clipped layers and saturation across film/paper pairs. Test bypass on slides, direct scans and B&W. Ship only as an explicit print rendering choice after review. [Model and thresholds](https://github.com/JamesQiu2005/SpektraLab/blob/b51e672/engine/src/core/negative_hue.hpp) · [Render gates](https://github.com/JamesQiu2005/SpektraLab/blob/b51e672/engine/tests/negative_hue_checks.py) |
| Chemistry and spectral upgrades | Python dev's Langmuir donor saturates with silver density. Evaluate against RS's linear DIR in both the correction and characteristic-curve construction. For RMS grain, match aperture, sampling pitch and density before comparing variance, spectrum and channel correlation. Experimental's Arctic beta04, revised neutral packs and method-specific white normalization form a separate calibration candidate. Its single-channel green-index failure does not transfer directly to RS, which broadcasts resolved B&W to RGB. Keep the accepted alpha02 and stock identities available. LAB's rem-jet-free model combines Fresnel reflection with assumed plate return and fitted layer absorption. Require stage-correct controls and point-light/scan references before selecting defaults.
